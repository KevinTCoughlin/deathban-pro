BEFORE YOU START

Good to know.

Does this permanently ban players?

DeathBan Pro applies temporary bans. In individual mode, ban durations increase by offense level according to your configuration. In shared mode, the empty-pool ban duration is configurable.

Can I protect a lobby or creative world?

Yes. Configure enabled-worlds and disabled-worlds to control where deaths count. The default configuration excludes world_lobby.

What about admins and player permissions?

The default deathban.bypass permission is granted to operators. Admin commands use deathban.admin. Review the permission defaults before testing or opening your server to players.

Where can I get help or report a problem?

Start with the troubleshooting guide, or open an issue on GitHub with your server version and relevant logs.
