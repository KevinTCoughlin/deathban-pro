DeathBan Pro

Hardcore Death Penalties Done Right

Bring hardcore-style consequences to your Minecraft server without the permadeath.
Temporary bans that escalate with repeated deaths — teaching players to play carefully.

Download Latest View on GitHub

Key Features

⏱️

Rolling Death Window

Deaths only count within a configurable time window (default: 24 hours). Die 3 times in 24 hours? You're banned. Survive 24 hours? Your counter resets.

📈

Escalating Bans

First offense: 1 hour. Second: 6 hours. Third: 24 hours. Fourth: 72 hours. Players learn quickly that carelessness has consequences.

🔄

Offense Reset System

Play safely for 7 days (configurable) and your offense level resets. Rewards careful gameplay!

👥

Shared Lives Mode

Create server-wide or team-based life pools. When the pool is empty, deaths trigger bans. Perfect for team challenges!

🎨

Seasonal Themes

Halloween theme with spooky particles and sounds. Default theme with classic red/gray colors. More themes coming soon!

⚙️

Full Customization

Every message, duration, and threshold is configurable. Supports MiniMessage (Paper) and legacy color codes (Spigot).

Commands & Permissions

Command Description Permission
/deathban Show help menu deathban.use

/deathban lives Check shared lives pool deathban.use
/deathban team create <name> Create a team pool deathban.use

/deathban reset <player> Reset offense data deathban.admin
/deathban pardon <player> Remove active ban deathban.admin

Configuration Example

# DeathBan Pro Configuration

mode: individual  # "individual" or "shared"

# Shared Lives (when mode: shared)
shared-lives:
  default-lives: 10
  max-lives: 20
  allow-teams: true
  empty-pool-ban: 1h

# Rolling window - deaths within this period count toward ban
rolling-window:
  enabled: true
  duration: 24h
  max-deaths: 3

# Ban durations by offense level
ban-durations:
  1: 1h      # First offense
  2: 6h      # Second offense
  3: 24h     # Third offense
  4: 72h     # Fourth offense
  5: 168h    # Fifth+ offense

# Offense resets after playing safely for this period
offense-reset:
  enabled: true
  clean-period: 168h  # 7 days

# Theme system
theme: default  # "default" or "halloween"
