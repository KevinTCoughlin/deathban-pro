HOLIDAY BREAK SMP

Ready before
the holiday break.

Christmas, New Year, winter or summer holidays: wherever you are, the break is when friends, cousins and siblings finally play together. Set the rules once and let every life count.

  1. 1

    Match your server version

    DeathBan Pro 2.0.0-alpha.1 needs Paper 26.3 and Java 25. On Java 21 or Minecraft 1.21, use v1.3.0-alpha.2. Both are alpha builds, so back up your world and try it on a copy first.

  2. 2

    Pick a mode for your group

    The default is individual: 3 deaths in 24 hours means a ban. For a team challenge, set mode: shared. The pool starts with 10 lives, and when it is empty each death means a 1-hour ban.

  3. 3

    Set up teams

    Run /deathban team create <name> and /deathban team join <name> to give each team its own pool. These need deathban.team.manage, which only operators have by default.

  4. 4

    Fit bans to a short break

    Repeat bans grow from 1 hour to 168 hours by default. Shorten ban-durations in config.yml so nobody sits out half the holiday, then run /deathban reload.

  5. 5

    Keep the peace

    By default, deaths in world_lobby do not count. If someone is banned right before the group logs on, an admin can run /deathban pardon <player>.

BEFORE YOU START

Good to know.

Which version do I need?

DeathBan Pro 2.0.0-alpha.1 needs Paper 26.3 and Java 25. Minecraft 26.4 is not supported yet. Servers on Java 21 or Minecraft 1.21 should use v1.3.0-alpha.2. On Java 21, the 2.0 plugin logs that it needs Java 25 and disables itself.

Does this permanently ban players?

No. Players can come back when their timer ends. You choose how long bans last. Admins can also use the pardon command to let someone back in early.

Can I show lives on my scoreboard?

Yes, with PlaceholderAPI and a scoreboard or menu plugin that supports it. Use %deathban_remaining_lives% for individual lives, %deathban_pool_lives% for shared lives, or %deathban_ban_remaining% for time left on a ban. See the docs for the full list. DeathBan Pro works without PlaceholderAPI too.

Can I protect a lobby or creative world?

Yes. Configure enabled-worlds and disabled-worlds to control where deaths count. The default configuration excludes world_lobby.

What about admins and player permissions?

The default deathban.bypass permission is granted to operators. Admin commands use deathban.admin. Review the permission defaults before testing or opening your server to players.

Where can I get help or report a problem?

Start with the troubleshooting guide, or open an issue on GitHub with your server version and relevant logs.
